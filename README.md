# Urban Grocers Project 
Automated tests for the Urban Grocers API, specifically the food kit creation section.

## Requirements to run the tests:
Prerequisites:

- Install the pytest and requests libraries:
  > > pip3 install pytest  
  > > pip3 install requests

## How to run the tests:
1. Clone the repository.
2. Install the required dependencies.
3. Run the tests using the command: `pytest create_kit_name_kit_test.py`.

## Files:
- `configuration.py`: Contains base URL and endpoint configurations.
- `data.py`: Provides the POST request bodies.
- `sender_stand_request.py`: Handles sending requests to the API.
- `create_kit_name_kit_test.py`: Contains automated tests using pytest.
- `README.md`: Project description.
- `.gitignore`: Specifies files and folders to be ignored by Git..

## Dependencies used:
- `requests`
